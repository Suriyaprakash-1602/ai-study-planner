# 🧠 AI Study Planner

A modern, AI-inspired study planning application that intelligently creates personalized daily study schedules based on your syllabus, exam date, available study hours, topic priority, and difficulty level. Designed to help students stay organized, improve productivity, and achieve consistent learning through structured planning.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/vishnupriyac240307/ai-study-planner.git
```

Move into the project folder

```bash
cd ai-study-planner
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```

# 💡 How It Works

1. Add one or more subjects.
2. Enter syllabus topics for each subject.
3. Assign priority and difficulty levels.
4. Select your exam date.
5. Specify available study hours per day.
6. Generate a personalized study schedule.
7. Track completed sessions and monitor progress.
8. Export your study plan as CSV or print it.
