# AI Study Planner

A responsive React application that converts subjects, syllabus topics, priorities, difficulty levels, exam date and available study time into a personalized daily study schedule.

## Features

- Add unlimited subjects and topics
- Priority and difficulty-based scheduling
- Daily session generation
- Revision and practice sessions
- Weekly rest day support
- Progress tracking
- LocalStorage persistence
- CSV download
- Print-friendly plan
- Dark mode
- Responsive design
- No paid AI API required

## Tech Stack

- React
- Vite
- JavaScript
- date-fns
- React Icons
- LocalStorage

## Run Locally

```bash
npm install
npm run dev
```

Open the URL displayed in the terminal.

## Build

```bash
npm run build

```
